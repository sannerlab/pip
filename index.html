Sanner Lab pip index

Python packages for the software of the Sanner Lab (Scripps Research), served as a pip index. The files themselves are attached to releases of sannerlab/downloads.

  • py37/: the Python 3.7 packages of ADCP 1.1 and ADFRsuite

Use it with --index-url only, never together with PyPI: some package names (for example prody) belong to unrelated projects on PyPI.

python -m pip install --no-deps --index-url https://sannerlab.github.io/pip/py37/ adcp==0.0.25

The ADCP 1.1 installation scripts do this for you: see ADCP 1.1 download.
